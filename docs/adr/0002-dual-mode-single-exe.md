# ADR 0002：一个 EXE 同时是 GUI 和 CLI

- 状态：已采纳
- 日期：2026-11-22

## 背景

工具类软件真实使用场景常常两半：白天手工点一下，夜里挂计划任务跑。若发两个可执行文件，
逻辑会分叉、版本会漂移。

## 决策

`DeskFlow.exe` 无参数启动窗口；带 `--run` 时走无界面批处理，并用 `AttachConsole(ATTACH_PARENT_PROCESS)`
附加到调用者控制台输出。两者共用 `JobEngine` 与 `JobCatalog`。

## 后果

- 只需维护一个发布物、一份版本号、一套日志格式。
- WinExe 子系统本身没有控制台，必须附加父控制台；被计划任务拉起时没有父控制台，输出自动退化为只写日志文件。
- 退出码承担"机器可读的结论"：0 成功 / 1 有失败条目 / 2 参数或运行错误。
- 参数解析手写（`CliHost.Parse`），不引入 System.CommandLine，减少依赖与行为不确定性。
